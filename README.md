## Installation
- Make sure the have python installed/configured !
- Open terminal

- Clone this repository

    ```
    git clone https://github.com/oehrasa/Auto-Written-Book
    ```

- Change directory to Auto-Written-Book

    ```
    cd Auto-Written-Book
    ```
- Create input folder

    ```
    mkdir input_folder
    ```

 - Install the necessary library

    ```
    pip install -r requirements.txt
    ```

# Usage
1. put our .pdf files into input_folder we created earlier
2. run it using `python pdfcon.py` or just use vscode built-in 
3. happy happy

## Dependencies
| Lib | Version |
